FPGA Snake Game

This project recreates Snake entirely in FPGA hardware, using a finite state machine to control game flow, VGA output to draw the board, and switch-based input for movement.

The design balances gameplay features with FPGA resource limits, requiring tradeoffs in grid size, apple generation, and snake length.

Project Overview

Modular FPGA design with movement logic, FSM control, apple generation, and VGA rendering.

Gameplay

Snake grows by eating apples and ends based on FSM-controlled conditions.

Architecture

Top module connects game logic, input, rendering, and timing.

Tradeoffs

Reduced board size, limited snake length, and deterministic apple placement.

FSM State Design

Idle State

Initializes the game, holds position, and waits for input.

End State

Stops gameplay and displays final condition when game ends.

FPGA Size & LUT Usage

Early versions exceeded FPGA capacity (>110%). Final design fits within ~1,399 logic cells.
