Interactive Desmos Clock

This project is a clock built with Desmos. You can manually set the minute and second values below and check whether the clock hands point to the expected positions.

The graph is static by default. It does not auto-run like a live clock. It updates once when the page loads, and again only when you press Set Time.

How it Works

The second hand angle is based directly on the selected seconds value, and the minute hand angle uses both minutes and seconds so it moves proportionally. 

\theta_s = 2\pi \frac{s}{60}
\theta_m = 2\pi \frac{m + s/60}{60}

This means the second hand completes a full rotation every 60 seconds, while the minute hand advances smoothly as seconds increase. 

second hand endpoint = (4.5\sin(\theta_s), 4.5\cos(\theta_s))
minute hand endpoint = (3.5\sin(\theta_m), 3.5\cos(\theta_m))
