Interactive Desmos Clock

This project is a simple clock built in Desmos. The graph includes sliders so you can manually change the minute and second values directly in the embedded calculator.

Use the sliders in the embedded Desmos calculator to change the minute and second values and test the clock manually.

How it Works

Inside the Desmos graph, the clock uses sliders for minutes and seconds: 

m = 15
s = 30

Those values are used to compute the hand angles: 

theta_s = 2π * s / 60
theta_m = 2π * (m + s/60) / 60

The second hand completes one full rotation every 60 seconds, and the minute hand moves proportionally as the seconds increase.

Once these sliders and equations are saved in the Desmos graph itself, the embedded version on this page will stay interactive without any extra JavaScript here.
