Interactive Desmos Clock

This project is a simple clock built in Desmos. It uses a dynamic tick function to move the hands, and can also be set manually.

How it Works

The clock’s hands move according to the following tick function: 

t_{ick}(x) = r_{ot} → r_{ot} + (x/1000) * (2π / 60)

You can also manually set the time: 

r_{exactTime} = r_{ot} → T_{time}

Try adjusting the parameters directly in the embedded Desmos calculator!
